Installation
============

Installing the package
----------------------

edifactlib is available on PyPI.
Install the package using ``pip install edifactlib``.

Optional extras
---------------

If you want to extend edifactlib, you should install the dev dependencies.
These can be installed with ``pip install edifactlib[dev]``.
To build the accompanying documentation locally, it is also recommended that you install ``edifactlib[docs]``.
