Supported EDIFACT Versions & Directories
========================================

Syntax versions
---------------

Currently, EDIFACT versions 2 and 3 are supported. Support for version 4 is planned. 

Directories
-----------

edifactlib supports the following directories:

- D.24A
- D.23A
- D.22B
- D.22A
- D.21B
- D.21A
